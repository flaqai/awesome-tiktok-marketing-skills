# Flyne AI 白博美舞蹈首帧

为后续 Kling motion control 制作 9:16 首帧。最新角色是白色、蓝眼睛的博美犬。旧草稿的深棕眼睛、预摆舞姿不再作为默认。

## 不能漂移的内容

- 使用用户最新确认的博美模板锁定脸型、眼睛、毛发、嘴鼻比例。纯白蓬松毛、圆脸、蓝眼、小黑鼻、短嘴、快乐神情。
- 可爱 3D 动画比例：略大的头、短小身体、短手短腿；不能逐次越画越高或变成人类成人体型。
- 拟人双腿自然站立，脚掌着地，光脚露出小爪子，不穿鞋。正常站立不是四足站立；前爪自然放松，不强制邀请手势、跨步或抬腿舞姿。
- 9:16，全身完整，主角约占画高 70–75%，耳朵、帽子和脚不裁切，四肢边缘清楚。

## 每一集的变化

记录最近使用的场景、配色、衣服版型、帽子和观众。新一集至少更换场景与完整服装设计；只换衣服颜色不算不同风格。帽子也不要反复同一种。

用户要 cute：日常童趣、明亮甜美。要 cool：街头运动、赛车夹克、复古唱片等视觉语言，但仍是亮色、阳光和短小可爱比例。色彩可以浓烈，但集中在少量主色，避免杂乱。

有观众时为每张图重新选择物种、数量、位置和反应。观众同样穿衣、拟人站立、同一种 3D 动画画风。远近错落且都看向主角，不能每次相同四只、相同站位，不能抢主角或遮住裸爪。

## 参考、编辑与输出

说明参考图继承的是身份、比例还是衣服。用户只要调整眼睛、腿长或服装时，只编辑该部分，保留原图的场景、光线和其他满意内容。

输出一条明确完整的图片 prompt；若已要求直接生图且工具可用则调用生图，再展示结果。提示词本身不等于已生成图片。未提供人物模板时，说明需要指定参考才能严格锁脸，不假装已看到旧图。

首帧通过后再交给 motion control：参考动作素材必须实际存在，模型可用性与输入规格以实际页面为准。本技能不自动生成付费视频。

检查顺序：同一只狗 → 蓝眼 → 短肢 → 双足自然站立 → 裸爪 → 新衣帽 → 不同观众 → 明亮干净。完整示例见 下方的「示例」部分。
