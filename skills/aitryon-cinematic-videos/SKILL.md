# AITryOn 真人女主与奇观短片

账号核心是固定成年女主参与可读的视觉事件。保持最新确认的棕色波浪长发女主身份，不把本账号换成 Seaimagine 的金发女主。实际参考图优先于文字概括。

## 先确定生成模式

- I2V：上传图就是第零秒。单画面，人物与触发物清楚，关键事件尚未完成；不用角色拼贴或分镜表当首帧。
- Reference-to-video：图片用于身份、服装、材质、地点等明确用途，不必是第一帧。角色参考图默认锁定完整造型；只有用户要求重新定装时才改衣服。
- 案例视频默认供创意分析。用户不上传案例时，最终 prompt 只引用真正准备上传的图片，所有动作和镜头用文字说明。

当前常用 30 秒；艺术短片通常 9:16，真人游戏片曾明确使用 16:9。按当次要求输出，不能用旧版 15 秒竖屏覆盖它。

## 创作与资产

先确定“角色想做什么 → 接触什么 → 世界如何回应 → 如何收尾”。沿用参考片的材质、动作因果和镜头逻辑，改变剧情细节；不自动将所有艺术题材替换为星空。

多图时逐张标注：编号、锁定内容、是否继承服装、背景是否继承。艺术世界通常可拆为女主定装、特殊材质世界、现实起终点三图。待生成图明确标为待生成，完成后按顺序上传。

## 两种导演路线

**艺术穿越**：真人皮肤与场景材质保持区分。让触摸、划水、推压真正改变材质；写出接触点、阻力、流动方向和余留痕迹。由现实进入另一世界，再回到同一现实空间，留下一个小物件作为结尾呼应。金色厚涂题材写调色刀脊线、沟槽、局部金箔，不能只写“金色”而变成光滑塑料。

**真人游戏**：第一秒进入动作。先标出威胁、掩体、路线，再安排奔跑、躲避、确认、应对。使用肩后追踪、急转跟随、接触反馈；瞄准时短暂稳定以看清目标。全程随机摇晃不等于刺激。跨越长距离和不同阶段时允许明确的比赛精华式时间跳切，不能一边要求连续时空一边瞬移。

## 提示词与交付

输出参考图片 prompt + 一份完整视频 prompt。视频顺序：规格、素材绑定、空间和角色锁定、镜头切换规则、连续时间轴、音效／音乐、关键禁止项。中文默认，图片可随用户指定语言。

时间段覆盖完整总时长；每段包含可表演动作与后果。动作片减少无关微笑和摆拍，高潮后再庆祝。需要 HUD 时定义少量准确文字及出现时点，复杂 UI 可留后期，不承诺模型能准确生成所有文字。

有 Seedance 2.5 导演技能时使用其模型语法与当前限制；没有时按本技能提供独立文本方案，并根据实际生成页面核对模式。不要硬编码旧平台限额，也不要自动提交付费生成。

示例见 下方的「示例」部分。核查身份、画幅、图片角色、动作先后、镜头位置、原路返回与声音是否一致。


## 示例

# 金色画中花园：30 秒结构示例

三张图先分别生成，随后按顺序上传。角色图生成时另附用户确认的女主身份图。

**图 1 定装**：9:16 单人全身真人摄影，保持参考中同一成年女性的棕色波浪长发、脸与身材；按本次新定装要求穿酒红色不透明泳装，小型哑光金环，赤脚。中性背景，皮肤纹理清楚，无文字。

**图 2 材质世界**：9:16 无人厚涂油画花园，蜂蜜金弧形斜坡连接浅颜料池，池边乳白花瓣、酒红花心和墨绿叶片；尽头金色弧墙有封闭的同心圆纹。保留调色刀痕、厚颜料脊线、局部金箔。空间可行走，有接触阴影与深度。

**图 3 现实起终点**：9:16 阳光下的普通度假泳池，米色池沿、蓝绿池水、棕榈树和弧墙；近侧水面浮着一片金色装饰画纹，远处乳白浮床。无人，建筑关系清楚。

```text
30秒，9:16，真人超现实艺术短片。@Image 1锁定成年女主完整身份与酒红泳装，不继承摄影棚。@Image 2锁定厚涂世界材质和斜坡—浅池—花园—弧墙的路线。@Image 3锁定现实泳池，开头结尾同一地点。仅使用三张图片。

0–4秒：女主从近侧池沿向水面金色画纹前倾入水。手先触碰，画纹在接触处撑开，双臂、头肩与身体依次进入。侧后方镜头跟随下沉，二维画纹展开为有纵深的金色空间。
4–10秒：连续跟随她向前划水两次。手掌将厚颜料推成弧形褶皱，沟槽稍后回填；她保持真人质感，颜料只少量附在前臂和小腿。镜头下降至侧面，前方浅池与花园逐渐出现。
10–15秒：切向花园侧前方。她脚掌触底、屈膝站稳、走出浅池，发现场景右侧半开的花，走近伸手。
15–21秒：切中景。她食指触碰花瓣，花先在接触处展开，邻近花苞沿路径依次开放。镜头轻微侧移，同时保留她、花和前方圆形墙纹。
21–26秒：切人物与弧墙同框。她沿花径走到墙前，双手推动圆形画纹，颜料沿圆周隆起后形成出口，门后可见原来的蓝绿池水。
26–30秒：她穿过出口时匹配切回现实泳池，扶住乳白浮床。一片金色花瓣从她指尖落入水面，接触后展开微小画纹。面容与服装保持原样。

仅在10、15、21、26秒切镜。轻柔原创弦乐，划动颜料、脚步、花瓣舒展与水声按动作发生；无对白。真实人体与厚涂材质清楚区分，空间有遮挡与视差，手碰到物体后才出现变化。无字幕、乱码和水印。
```

回归场景：若用户说“只上传人物图，不上传游戏案例视频”，输出必须仍自足；不能出现 `@Video 1`，不能用“照原片动作”替代动作描述。
