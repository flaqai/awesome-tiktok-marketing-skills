# Flaq AI／UGC Maker 模型展示

同一来源对话中有两个品牌，先明确本次是哪个。Flaq AI 侧重模型效果展示与对比，包装标出品牌和实际模型名；UGC Maker 可做广告素材与吸引普通观众的视觉内容，不能把所有请求都改成广告主教程。

## 不可遗漏的修正

- 最终 prompt 是确定方案，不写“红色或蓝色”“咖啡馆／工作室”等让模型选择的分支。构思阶段可以比较选项，交付时选定。
- 不把未上传的原案例名称、场景或道具写进负面词。只写本片需要的内容与相关约束；避免为了说“不照搬”反而引入原片元素。
- 首帧要在本次主事件之前：准备踢球，而不是球已飞走；准备接触，而不是变化已完成。若用户明确要动作中的开场，则以其指定状态为准。
- 后续已支持 reference-to-video。不能继续强制所有参考图成为首帧。角色图、道具图、场景图、界面截图各有明确职责。
- 中文视频 prompt，品牌名、模型名及指定英文台词保留英文。

## 模型对比

两个模型使用相同素材、故事、时长、画幅及尽量一致的 prompt；只为不兼容语法做最小适配，并说明差异。不得编造某模型可用或某方胜出。

选择可观察的比较点：人物身份、接触物理、动作完成、速度与尺度、镜头连续、材质和品牌可读性。后期清楚标注实际模型名；模型支持的参数不一致时公开说明，不能宣称完全同条件。

## 品牌融入

品牌文字放到自然承载物：降落伞布、设备箱、衣服、机械装甲板、蛋糕字牌或最终屏幕。先选定一个清晰位置，再锁定其连续性。不要把品牌字无缘无故浮在空中。

文字必须准确：本次选 Flaq AI 或 UGC Maker。若模型生成文字不稳定，提出后期替换／叠加，不宣称 prompt 能保证拼写。不要用“无任何文字”同时要求品牌出现。

## 节奏与参考图

保留参考片的视觉爆点与因果结构，重新设计地点、主体和道具。15 秒版先保留关键动作，再压缩过场。追逐必须有具体危险打断动作，变形明确部件来源和归宿，纪录片明确物种和各自环境。

素材表包含编号、角色、活动时段、保留项、不继承项。角色身份参考默认保留服装，用户要求新造型时先出新定装。最终 prompt 只引用实际准备上传的资产。

## 交付

品牌与模型说明 → 图片 prompts → 素材表 → 一份完整视频 prompt → 用户需要时附平台文案。时间线总长精确，拍摄视角与空间路线自洽，声音在接触之后响应。具体模型限制以实际页面／官方说明为准。

标题围绕可见事件，说明品牌与实际模型，不编造播放量或效果承诺。准备文案不代表自动发布。示例见 下方的「示例」部分。


## 示例

# 对比与品牌落点示例

## Flaq AI：10 秒屋顶回弹

参考图 prompt：单人全身成年女性运动员定装图，电蓝运动套装、扎起的金发、黑色训练鞋，真实皮肤与服装结构，灰色背景；以选定图作为两个模型共同的人物参考，不作为首帧。

```text
10秒，9:16，虚构电影特技。@Image 1锁定成年女主完整外貌与服装，不继承灰色摄影棚。夜晚城市屋顶，绿色停机坪、低矮护墙，后方三名朋友；街道中央正对起跳点是一座巨型圆形弹性装置。屋顶左侧黑色设备箱印有白色“Flaq AI”。
0–2秒：女主助跑越过护墙。屋顶朋友手持手机从背后跟跑到墙边，向下俯拍，机位留在屋顶。
2–4秒：她沿楼间向黑色弹性面中心下降，身体随距离自然变小，镜头持续追踪。
4–5秒：双脚接触中心，弹性面下陷，达到最低点后恢复形状，将她向上弹出。接触、压缩、回弹四阶段可见。
5–8秒：她沿原路线升起，完成一次团身翻转后展体，双脚朝下寻找原屋顶。摄影者由俯拍连续抬镜跟随。
8–10秒：她越回同一护墙，双脚落地，屈膝下沉缓冲后站稳，朋友靠近欢呼。设备箱品牌仍位于左后方。
一镜到底，手机广角，速度来自环境尺度变化与追踪。脚步、风声、弹性面拉伸声、回弹声、落地声和欢呼同步，无对白。品牌只有“Flaq AI”，其余无可读文字。人物与道具保持完整，动力来自弹性装置，不发生瞬移。
```

分别用于本次明确选择的两款模型，包装时填入真实模型名；此例不宣称模型的当前可用性。观察落点、压缩、原路返回、人体与落地重量，不只比较画面漂亮程度。

## UGC Maker：机械变形品牌连续性

两张参考图分别为摩托与最终机甲。先在摩托左侧六边形装甲板上放“UGC Maker”，最终机甲胸口使用同一块板。写清前后轮变为双肩、车架变为胸背、装甲板沿连接机构转至胸口，不能无中生有。

15 秒分配：0–3 高速前进；3–6 连续避开障碍；6–9 跨越缺口；9–12 可见机械变形；12–15 重型落地与胸口品牌。风声、机械锁定声、脚掌撞地声各有触发点。只确定一种环境，不给模型同时选择冰路与雨桥。
