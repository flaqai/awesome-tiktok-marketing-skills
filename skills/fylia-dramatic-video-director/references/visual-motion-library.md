# 反差意象、动作与运镜语汇

这些是从对话中提炼的创作候选，不是经播放数据证明的词表。每片选少量相容的组合；具体动词、空间和因果比术语数量更重要。

## 强反差意象

| 对比 | 可直接转写的画面 | 应写清的关系 |
|---|---|---|
| 庞大体型 × 敏捷能力 | 她从深深压陷的软垫中弹起，庞大的身体收腿翻过，随后双脚干净落定 | 原体型不变，接触和弹起相继发生 |
| 沉重落脚 × 摇摆小物 | 鞋底落上椅面后，椅子猛沉，水沿两侧掀开；她在翻倒前已经蹬向下一落点 | 翻倒发生在受力后，不提前倒 |
| 身体向上 × 环境向下 | 她离开船头向外跃起，身后的船头却继续切入水面，船尾逐渐抬高 | 同框看见相反运动，不能只追人 |
| 日常材料 × 巨大尺度 | 白色糖果从破纸箱流入棕色积液，一小片气泡迅速鼓成高耸喷柱 | 先有实际接触，再升级规模 |
| 近处完整人形 × 远方小点 | 她从画面中可辨认的全身逐渐缩成空中剪影，最后消失在道路消失点附近 | 是距离变化，不是身体变形 |
| 压缩 × 释放 | 坐垫先压成深窝，边缘水线升高，回弹才把她送向下一目标 | 区分柔软坐垫、刚性框架和液体 |
| 局部日常 × 后续奇观 | 起初只有跑道和人物，抬镜后才看见她越过器械上空 | 首帧不剧透完整装置 |
| 空中混乱 × 落地从容 | 披发沿翻转弧线甩开，落地后双膝柔和下沉，站直时露出自信笑容 | 先停止主要惯性，再完成优雅姿态 |
| 意外发生 × 本人迟一拍理解 | 她浮出水面抹掉脸上的水，回头才发现身后只剩翘起的船尾 | 视线落到对象后才出现表情变化 |
| 险情递进 × 终点奖励 | 最后一件大家具在跟拍中揭示；站稳、伸手、拔旗、举旗，掌声随后释放 | 旗杆必须真正脱离插槽 |

主角始终是有行动意愿的角色。冲击力由动作、物体尺度和超现实结果产生，不添加对种族或身体的贬低。

## 动作连接语言

优先写可见状态转换：

- “落脚的瞬间屈膝，借回弹立即进入下一跳。”
- “上一段的前向惯性把她带过低点，再抬向下一落点。”
- “双手抓稳后身体重量转移到杆上，脚随后离开支撑。”
- “撑台推离后展开完整腾空轨迹，最后一周打开身体寻找落点。”
- “物体向一侧倾斜，她移步把重心送回中央，顺势继续前进。”
- “先接触，后压缩，再回弹；材质反馈可夸张，先后顺序清楚。”
- “门失去支撑后，前倾的纸箱自行滑落，撞地后破裂。”

不要用“疯狂做各种高难度动作”代替动作链，也不要给一个节拍指定互不相容的转向、道具和镜头。

## 运镜词必须带目标和时机

| 手法 | 可用表达 | 适用与边界 |
|---|---|---|
| 侧向全身跟拍 / lateral full-body tracking | “沿跑道同侧向右跟随，让她和下一个落点轮流成为画面中心。” | 闯关、运动；不突然越轴 |
| 顺动作揭示 / motivated reveal | “她蹬离蓝桶时，镜头右移，前方沙发首次进入画面。” | 最重要的首帧悬念工具 |
| 低机位上摇 / low-angle tilt-up | “双脚离台后上摇，完整身体越过器械顶端，场馆灯架进入背景。” | 显示高度；不切到不可到达的空中机位 |
| 跟落下摇 / tilt-down follow | “身体打开后随下降压镜，落地垫在脚接触前进入画面。” | 不能落地后才补拍落点 |
| 放宽看全动作 / widen for action | “起跳前略放宽，头、脚和支撑物均有空间，翻转完整入画。” | 不边翻边切成脸部特写 |
| 保持反向运动同框 / opposing-motion framing | “保持侧前方中远景，看见她向上跃出与船头向下钻入水中。” | 环境反应就是笑点时使用 |
| 短促数字推近 / digital punch-in | “对准桶内上升的液位短推近，保持足够时间看清灌满。” | 车内手机；不用作昂贵电影推轨 |
| 先拉广找人再追小点 / zoom-out reacquisition | “冲天后先回退找回完整轨迹，再短暂放大远方人影。” | 追拍失控飞行；不反复乱拉 |
| 有克制的手持修正 / restrained handheld correction | “喷流扑到玻璃时轻抖一下，马上稳住，中央视野仍清楚。” | 不能把高潮全部遮掉 |
| 动作匹配切镜 / match-on-action cut | “在一次已经落稳的节点切到同侧机位，保持前进方向。” | 仅用户允许剪辑时；不能藏掉失败动作 |
| 结果保持 / payoff hold | “举旗后保留约一秒全身，水波和旗布继续运动。” | 短暂收束，不自动冻结画面 |

一拍一个主要镜头任务。写“一镜到底”后不再写反打、瞬移高空俯瞰或跨场切镜。手持手机不默认搭配极浅景深、无晃动环绕和自动变焦电影镜头。

## 真实质感语汇

按场景取少量，避免通篇同一电影滤镜：

- 体育馆：浅色助跑道、暗一些的看台、顶部灯光、清晰掌脚接触、落地垫的局部压陷。
- 水上：身体接触后水线攀升、物体周边排水、扩散波纹、湿衣持续变深、桶环纹显示转动。
- 公路车内：挡风玻璃边缘、少量反射与雨点、仪表台下沿、消费级数字变焦、轻微自动对焦调整。
- 广场表演：隔离栏、局部举手机的人群、建筑垂线衬托高度、仰拍但不把全场一次交代完。

“写实”控制外观与事件的可读性；“超现实”控制幅度。不要一面禁止不现实，一面要求她像火箭飞向天际。

## 音乐与动作卡点

| 类型 | 可选音乐 | 节奏与音效 |
|---|---|---|
| 马戏连续特技 | 原创电子摇摆乐，约150–165 BPM，铜管、管风琴、军鼓与电子低音 | 越障保持主题推进，接触落重拍，最后亮相铜管收束 |
| 体育馆与水上闯关 | 原创体育电子乐，约145–160 BPM，底鼓、拍手、明亮合成器 | 关键起跳前短抽拍，撑台/落地音清楚，稳落后胜利旋律 |
| 游艇与连锁事故 | 轻快热带放克，约110–125 BPM，拨弦与弹性低音 | 平常气氛先建立，环境突变低音下滑，水声接管高潮 |
| 可乐喷射远飞 | 喜剧电子放克，约135–145 BPM，紧凑鼓点与滑音 | 箱子落地干脆重音，气泡前留空隙，起飞低音爆发，远去人声衰减 |

BPM只是创作起点。十几秒短片用同一音乐主题，通常安排3–5个关键同步点即可，不给每一步都添加新段落。可以轻微麦克风过载或现场失真，但不牺牲重要声音可辨认性。

## 结尾选择

- 竞技：双脚接触、膝盖缓冲、重心稳定、站直举臂，披发回落肩背。
- 闯关：到达、站稳、握旗、拔出、举起，人群在目标真正完成后欢呼。
- 事故：前景主角反应与后景异常结果同框，例如回头看仍在下沉的船。
- 远飞：人物逐渐消失，近景触发源仍持续运作，空旷远方留下余韵。

按用户要求选结尾；不要把所有片子改成灾难、摔倒、胜利或冷面望镜头。
