## 用户提供成片的可见支持

`fylia ai jump piano.mp4` 由用户说明是修改先前提示词后得到的成片。对话中查看关键帧显示：

- 开场是披发女主角、岸边、水面与第一把椅子；并非整个路线的全景地图。
- 镜头跟随人物后才依次看到红桌、黄桶、蓝桶、绿色沙发和终点钢琴。
- 主角为白色短背心、黑色白边短裤，黑色长卷发披散。
- 结尾到达钢琴、取得旗帜，形成清楚完成状态。

这支持“逐步揭示”的导演方向和该次人物外观，不证明每个旧 prompt 条款有效。不要声称该视频验证了其他场景、文案、BPM或模型能力。

## 旧稿里需要主动纠正的地方

1. **全景首帧过载**：早期马戏、水上路线要求全套器械、终点和人物同时清楚，导致人物被缩小、过程被剧透。新版首帧只交代起点。
2. **马尾残留**：旧稿多次写高马尾。新版所有相关字段与动作描述统一为披发，包括倒立和落地段。
3. **擅改跑道几何**：广场源片可见单面高弧坡、向外翻腾后回到原可见坡面；旧稿却添加了越过顶部后的背面下降坡。未经用户要求，不把这种补充当作源片事实。
4. **上传限制只检查单段**：体育参考约27.5秒，加jump piano约15秒会超过本地Seedance文档规定的参考视频合计时长。后者只作为偏好示例即可，不自动一起上传。数字仅是当次文件检查，未来重新读取实际素材和模型限制。
5. **只看长片前半段**：水上参考约61.5秒，前30秒不包含最终结尾。应覆盖全片，超限输入先裁剪或重选参考，不能仍写原文件可直接上传。
6. **参考片结尾误述**：水上原参考尾段有到岸、奖杯与大铃等画面，用户要求的“特殊大家具拔旗”是用户指定改编，不应说成原片本来如此。
7. **无效精细控制**：固定到每一步多少厘米、同时几种旋转、每件物品的多重反弹，会挤掉可读动作时间。保留重要接触与状态转换，删重复微指令。
8. **旧场景限制污染**：不能把“无动物、无马桶、无火圈”等上一个故事的禁项复制到每个新片。只保留会影响当前结果的约束。
9. **案例泛化过度**：旧工作区文档的农村背景、头巾、单一事故、固定10秒和定格收尾不是最新通则。不要用旧模板覆盖后来的连续挑战与体育成功表演。

## 自审用回归场景

不需要自动生成媒体。检查新 skill 或提示词面对这些要求是否会做出正确决策；结构检查不能证明成片质量。

| 输入 | 应有行为 | 失败信号 |
|---|---|---|
| “15秒体育馆，参考这段，最后漂亮落地” | 单一表演主线、披发、局部助跑首帧、后续撑台入镜、完整翻腾与稳落 | 首帧全器械地图；凭空改成跑坡事故；束发 |
| “只要视频prompt” | 只交付一个可复制代码块 | 又输出图片prompt、长方案和表格 |
| “10秒跳水压沉船” | 保留10秒，镜头看清人上升与船下沉，再呈现结果 | 自动变15秒；追人特写导致船不见；变普通成功跳水 |
| “箱子自己掉，不是她倒” | 开门失去支撑、掉箱、撞裂、糖接触可乐后喷发 | 角色搬箱倒糖；完整包装先产生喷柱 |
| “参考60秒视频，压到15秒” | 覆盖全片分析，处理上传限制，重新编排关键段 | 只看前半；让用户直接上传超限原片 |
| “第二个视频只是告诉你首帧要这样” | 学习表达方式，不必上传第二段 | 把所有附件自动绑定到生成任务 |
| “按参考单面弧坡上去，翻身下来” | 沿源片几何设计连续往返轨迹 | 添加未要求的另一侧下降坡 |
| “这次她戴帽子，把头发扎起来” | 用户当次明确造型覆盖默认，更新所有段落 | 为遵守本skill拒绝用户的新造型 |
